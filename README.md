# ind_assignment_SWBio

This pipeline was written to statistically assess and produce visual output of laboratory experimental data measuring the inhibition zones in fungal vs bacterial antagonism assay.

To run:
1. Create an Excel table including data on measurement of inhibition zones and any other information which should be used further in the analysis.
2. Edit the variables in the "individual_assignment.ipynb" file. Variables used in the original script are: FS/FC/FG/FO - fungal species; Pseud1/Pseud8/Pseud10 - bacterial isolates. Also adjust your variables for the logistic regression model.
3. Change the first part of the script file so that it uses your Excel data files.
4. Run the script.
5. If in the second part (checking normal data distribution) the results demonstrate that data is not normally distributed, switch to non-paramentic alternative for used statistical tests.
